# 0.5 永久天赋与营地仓库

当前 0.6 的敌人类型与战斗提示更新见 `10_Enemy_Variants.md`；本文件的仓库与天赋规则继续适用。

日期：2026-11-03。引擎 UE4.27.2，C++ 核心 + 蓝图。默认地图仍为 `/Game/AshenRift/Maps/L_RandomDungeon`，不覆盖旧版本地图。此版本使撤离带回的装备和符文可用于下一局。

## 操作

出生营地附近按 B 打开或关闭准备面板。1 / 2 选择战士或法师；T 购买生命天赋，Y 购买攻击天赋。上下方向键选择仓库物品，右方向键增加一件携带数量，左方向键减少一件。E 按当前选择出发；关闭面板保留本次选择，但不扣仓库。选择保存在本次程序会话中，退出程序后须重新准备。

面板显示银行金币、符文、天赋等级、下一级价格、各物品仓库总数与计划携带数。背包 Tab 和营地面板互斥。离开营地自动关闭准备面板；天赋、仓库和职业切换只允许在安全营地区域使用。

## 永久天赋

| 天赋 | 每级效果 | 等级上限 | 每级价格 |
|---|---|---|---|
| Vitality（生命） | 最大生命 +10 | 3 | 1 / 2 / 3 已存符文 |
| Might（攻击） | 所有玩家攻击与技能伤害 +2 | 3 | 1 / 2 / 3 已存符文 |

两个职业共享天赋。满级战士基础生命 130，法师 105；最大永久伤害加成 +6，与装备和本局商店强化叠加。购买成功后在安全营地恢复基础满血；进入副本后不能购买。装备护甲的反复装卸仍不能治疗。

购买先构造档案候选，检查存盘结果后才替换内存档案；失败不扣符文或增加等级。满级、余额不足、未知天赋或非营地操作都被拒绝。原档案 SaveVersion 保持 1，旧版本已有的空 TalentRanks 可直接加载；新增加载校验拒绝负数库存或非法等级，并保留原文件。

## 仓库与出发

仓库支持 IronSword、OakStaff、LeatherArmor、RunicCharm 和 Potion 五种物品。每种装备最多携带 1 件，药水最多 5 瓶；战士只能准备剑，法师只能准备法杖。切换职业会取消旧职业武器的携带选择，不扣任何物品。

准备操作只编辑临时清单。出发必须满足背包为空、物品仍有库存、堆叠和格子足够。先保存扣除选中物品后的档案，成功后一次性填入副本背包，再进入 InDungeon；失败保持营地、仓库和准备清单。武器、护甲与饰品自动装备，开始时按装备后的生命上限恢复满血。

出发扣除已存盘，因此强退不退还已带入物品。副本死亡时携带物品与新拾取物品一并损失；未携带库存、银行和天赋保留。成功撤离把剩余物品与新战利品一起加入仓库，没有额外的“返还原物品”分支，避免重复入库。已经使用的药水不会返回。重复结算仍由现有阶段锁拒绝。

仓库数量按 ItemID 堆叠，没有独立装备实例、保险、售卖、整理、合成或装备词缀。未消耗的银行金币目前只展示，商店仍花费本局金币。

## 代码入口

- `Source/AshenRift/ARCamp.cpp`：天赋购买、营地条件、携带选择、面板输入、基础生命计算。
- `ARRunGameInstance`：准备清单、出发保存事务、档案加载校验；原死亡和撤离结算继续复用。
- `ARPrototype.cpp`：输入绑定、出发自动装备与准备面板绘制。
- `AREquipmentComponent.cpp` 与 `ARProgression.cpp`：永久加成与职业、护甲、技能的组合。
- `Tests/ARCampTests.cpp`：真实游戏世界中的营地集成回归；测试使用唯一隔离存档，不修改玩家档案。
