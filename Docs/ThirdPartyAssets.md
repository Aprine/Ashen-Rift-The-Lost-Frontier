# Third-party environment assets

## KayKit dungeon environment

- Creator: **Kay Lousberg / KayKit**.
- Imported UE assets: `Content/AshenRift/KayKit/` (215 packages).
- Delivered by teammate **Kuangxin**, together with the room/camp layouts, in
  [source commit e2dfc0b](https://github.com/kuangxin114514/Ashen-Rift-The-Lost-Frontier/commit/e2dfc0b83847e912f477b9bc0ecd9c0046c2f729).
- Creator's [Dungeon Pack page](https://kaylousberg.itch.io/kaykit-dungeon-pack)
  identifies the pack as **Creative Commons Zero (CC0)**.
- [Official archived license](https://github.com/KayKit-Game-Assets/KayKit-Dungeon-Remastered-1.0/blob/b0ca9bd96a8072ab36a3a5464f00ed1e06a16d07/LICENSE.txt),
  [CC0 1.0 terms](https://creativecommons.org/publicdomain/zero/1.0/).

The delivered repository includes imported meshes, one material and one texture;
it does not include the original FBX archive or establish an exact pack version.
The existing Unreal packages are used directly; no paid asset pack was acquired
for this integration. Environment assets are not claimed as original team art.
The layout work and gameplay integration are credited separately in the release
notes. This notice does not assign a license to the project's own source code.

## 0.10 town and expedition delivery

- `Content/Environments/KayKitMedieval/` has 22 packages for the town from Kuangxin's [hub commit](https://github.com/kuangxin114514/Ashen-Rift-The-Lost-Frontier/commit/504548eab670760d630f93ac4df2280e31786df3). The [KayKit Medieval Hexagon Pack](https://kaylousberg.itch.io/kaykit-medieval-hexagon) is by Kay Lousberg and is published under CC0.
- `Content/Environments/KayKitDungeon/` has 74 UE packages from Kuangxin's [dungeon commit](https://github.com/kuangxin114514/Ashen-Rift-The-Lost-Frontier/commit/28409168f8af23470a03b9a3b0da41e12dc404e6). These imported copies retain the original package paths referenced by the two levels. Author and license for the KayKit Dungeon pack are given above.
- `Content/Environments/Materials/` has eight grass and cobblestone packages supplied with the hub. The texture import filenames identify ambientCG's [Grass 001](https://ambientcg.com/view?id=Grass001) and [Paving Stones 037](https://ambientcg.com/view?id=PavingStones037), available under [CC0 1.0](https://docs.ambientcg.com/license/).
