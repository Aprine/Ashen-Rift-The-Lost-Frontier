# 0.18 方向闪避

2026-11-28 · Unreal Engine 4.27.2 · Windows Development

战士和法师在地牢地面按 **左 Shift** 或 **右 Shift** 即可闪避。与 **WASD** 同按时，方向相对镜头计算。松开方向键时沿角色当前朝向闪避。

| 项目 | 初始参数 |
|---|---|
| 位移 | 0.24 秒，地面畅通时约 3.6 米 |
| 免伤 | 起手后 0.18 秒 |
| 冷却 | 从起手算起 0.95 秒 |

闪避可取消尚未打出的横斩、旋风斩或施法。法术释放前取消时保留法力。离开墙边时可以用侧向闪避，朝墙闪避会在碰撞处停下。闪避使用现有移动动作，HUD 会显示「闪避中」「冷却」或「就绪」。

在随机遗迹里，可以用闪避应对灰烬守望者的砸地、横扫和肘击。蓝阵和金阵都以当前位置判定撤离，闪避移出范围会立刻中断。Esc 暂停会冻结位移、免伤窗口和冷却。
