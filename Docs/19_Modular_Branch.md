# 0.13 地牢三模块化支路

2026-11-26 · Unreal Engine 4.27.2 · Windows Development

进入地牢三后，到路线牌按 **E**，再按 **4** 或点击 **预览随机支路**。点击一个房间，HUD 会引导你走到绿色传送点。按 **E** 进入支路后，用 **M** 查看路线图和当前位置，或改选要去的房间。

支路由入口、战斗大厅、岔路、补给、精英和撤离六个模块组成。种子决定补给和撤离房接在战斗大厅还是后面的岔路上，还会改变布局方向和精英掉落。地图上每条线对应一个实际门洞，都可以双向通行。玩家可以从支路的蓝色撤离阵带出战利品，也可以沿路回到绿色入口去主地牢继续探索。往返使用同一个角色、本局金币、背包和商店库存，打过的精英也会保持已清理状态。

## 房间编辑

在地牢三中选中 `ExpeditionBranchWing`，可编辑六个房间预设的道具、阻挡范围与灯光。模块以 20 米为一格，门洞均位于边界中央。生成器用同一组连接数据绘制地图和拼接房间。场景道具复用组员地图已有的 KayKit Dungeon 资产。入口与导航区域的摆位可在完整 UE4.27.2 编辑器中复现。[配置脚本](../Scripts/configure_dungeon_three_routes.py) · [资源署名](ThirdPartyAssets.md)
